# Makam Yolculuğu · Makam Journey

Rast, Hicaz, Uşşak… Türk müziğinin makamlarını kulaktan tanı

Seyri dinle; makamı, karar sesini (durak) ya da yanlış perdeyi bul. Sesler 53 komalı dizgeyle çalınır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Müzik ve Ritim merkez uygulamasının oyunu; ortak motor: [muzik-motoru](https://github.com/taktemurr-ops/muzik-motoru).
